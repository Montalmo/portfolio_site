Create a "Contact Me" section and a "Footer" for a UI/UX designer's portfolio website.

**CRITICAL INSTRUCTION: ALL TEXT CONTENT MUST BE IN UKRAINIAN.**

**DESIGN SYSTEM (REQUIRED):**
- Dark Mode is mandatory (backgrounds in very dark gray or true black, e.g., #0f172a or #000000).
- Typography: Use a modern sans-serif like Inter or Outfit. High contrast for headings (white or near-white), softer gray for body text.
- Accent Color: Vibrant Violet (#8B5CF6).
- Feel: Premium, spacious, minimalist, and dynamic.

**Page Structure:**
1. A Call-to-Action section:
   - "Маєте ідею для проєкту?" (Have an idea for a project?) as the main headline.
   - A short encouraging description in Ukrainian.
   - A large, prominent "Написати мені" (Write to me) button.
2. A Footer:
   - Links to social/professional profiles: Dribbble, Behance, LinkedIn, Instagram.
   - Copyright notice in Ukrainian (e.g., "© 2024 Портфоліо UI/UX Дизайнера. Всі права захищено.").
   - Location or simple contact info.
3. Use subtle violet glow effects for the CTA section.
4. Minimalist and clean.
